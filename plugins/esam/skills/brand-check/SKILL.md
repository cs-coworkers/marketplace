# Brand check

Run Sam's access check (step 1 of the **sam** skill) if it hasn't run this session; if it stops, stop here too.

1. Read `policy/brand.md` and `coworkers/sam/lessons.md` from the Start folder; a past correction in
   lessons counts as a brand rule. If brand.md is missing, use these defaults and offer to
   create one later: plain words, specific over vague, no hype ("revolutionary", "game-changing"),
   no invented facts, one clear call to action.
2. Check the copy and list findings as a table: line · rule · problem · fix. Order by severity.
3. Check facts separately: every number, date, price, name and claim either comes from the folder
   or a cited source, or is flagged `[check]`. Flag any claim about another company or its product
   (a partnership, an endorsement, a comparison) unless the member's folder backs it.
3a. Check channel fit when the copy is for a channel: length, where the hook falls, links and
   hashtags (the limits in **social-week**, step 3).
4. Verdict in one line: PASS, PASS with fixes, or FAIL (with the one thing that must change).
5. Offer to apply the fixes; change the copy only after a yes.
