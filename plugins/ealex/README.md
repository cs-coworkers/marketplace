# Alex (ealex)

Alex is the managed startup cofounder agent from Coworkers.Global. Alex keeps a founder's company
records in their own Start folder and runs the rhythm accelerators impose: a monthly runway and
default-alive check, a weekly KPI and focus review, a monthly investor update, customer interviews
scored against the founder's premises, quarterly pivot-or-persevere reviews, an investor-style read
of the plan or deck, idea tests, and raise preparation with a full raise checklist.

Setup: install Chet first and say "Chet, onboard Alex". Access comes from the Start connector
(Google sign-in). Then say "Alex, cf-status" to begin. Alex proposes every file change and never
sends, posts, pays or signs anything.
