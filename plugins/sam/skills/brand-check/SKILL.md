# Brand check

1. Read `policy/brand.md` from the Start folder. If it is missing, use these defaults and offer to
   create one later: plain words, specific over vague, no hype ("revolutionary", "game-changing"),
   no invented facts, one clear call to action.
2. Check the copy and list findings as a table: line · rule · problem · fix. Order by severity.
3. Check facts separately: every number, date, price, name and claim either comes from the folder
   or a cited source, or is flagged `[check]`.
4. Verdict in one line: PASS, PASS with fixes, or FAIL (with the one thing that must change).
5. Offer to apply the fixes; change the copy only after a yes.
